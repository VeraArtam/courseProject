# Курсовой проект: Автоматизация тестирования сервиса покупки тура

Проект посвящён автоматизации позитивных и негативных сценариев покупки тура через веб-сервис aqa-shop.jar. Тестируются UI-сценарии формы «Обычная оплата» и проверки корректности записи данных в СУБД MySQL. Банковские операции эмулируются внешним симулятором.

Документация проекта доступна в папке docs/:

Plan.md *План автоматизации*

Report.md *Отчёт о тестировании*

Summary.md *Итоги автоматизации*

## Начало работы

### Prerequisites (что нужно установить)

Перед запуском убедитесь, что на вашем ПК установлены:

JDK 11 или выше (проверка: java -version)

Docker Desktop (проверка: docker --version)

Git (для клонирования репозитория)

Браузер (Chrome или Firefox)

Важно: Docker должен быть запущен до выполнения любых команд ниже.

### Установка и запуск

**Шаг 1. Клонирование репозитория**

bash

git clone https://github.com/VeraArtam/courseProject

cd courseProject

**Шаг 2. Запуск контейнера с MySQL**

Выполните команду для создания и запуска базы данных MySQL в Docker. Пароль и имя базы можно изменить, но тогда не забудьте обновить их в application.properties (см. шаг 3).

bash

docker run --name mysql-aqa -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=aqa_shop -p 3306:3306 -d mysql:8.0

Проверьте, что контейнер работает:

bash

docker ps

В списке должен быть контейнер mysql-aqa со статусом Up.

**Шаг 3. Настройка подключения к БД**

В файле application.properties (рядом с aqa-shop.jar или в папке resources) заполните:

properties

spring.datasource.url=jdbc:mysql://localhost:3306/aqa_shop

spring.datasource.username=root

spring.datasource.password=root

Остальные настройки (URL банковских сервисов) уже заполнены и менять их не нужно.

**Шаг 4. Запуск тестируемого сервиса (SUT)**

Откройте терминал в корне проекта и выполните:

bash

java -jar ./artifacts/aqa-shop.jar

Дождитесь сообщения Started ShopApplication in ... seconds. Приложение будет доступно по адресу:

text

http://localhost:8080

Не закрывайте это окно терминала — сервер должен работать во время выполнения тестов.

**Шаг 5. Запуск автотестов**

Откройте второе окно терминала (не закрывая первое) и выполните:

bash

./gradlew test

Для запуска с генерацией отчёта Allure:

bash

./gradlew test allureReport

После выполнения тестов отчёт Allure можно открыть командой:

bash

./gradlew allureServe

**Шаг 6. Остановка окружения**

После завершения тестирования остановите приложение (Ctrl+C в окне с aqa-shop.jar) и удалите контейнер MySQL:

bash

docker stop mysql-aqa

docker rm mysql-aqa
