# 1. Что было запланировано и что реализовано
   ## Запланировано

   *В соответствии с Plan.md:*

- **Настроить окружение:** MySQL в Docker, запуск aqa-shop.jar, доступ к симулятору банка.

- **Провести ручное тестирование обеих форм:** «Купить» и «Купить в кредит».

- **Автоматизировать UI-тесты для формы «Обычная оплата»** (18 сценариев: TC-01…TC-18).

- **Реализовать проверки в БД после каждого сценария** (JDBC + HikariCP).

- **Настроить отчётность Allure.**

- **Оформить найденные баги в Issues.**

- **Подготовить Report.md и Summary.md.**

    ## Реализовано

  - **Настройка окружения**	 MySQL 8.0 в Docker, aqa-shop.jar на порту 8080, симулятор банка доступен
  
  - **Ручное тестирование обеих форм**	Найдено 14 дефектов, оформлены в Issues
  
  - **Автотесты для формы «Обычная оплата»**	18 тестов (TC-01…TC-18), Selenide + JUnit 5, найдено 6 дефектов, оформлены в Issues 
  
  - **Проверки в БД**	DbHelper с JDBC, проверки статуса, количества записей, отсутствия данных карт
  
  - **Отчётность Allure**	Подключён плагин, генерируется ./gradlew allureServe
  
  - **Оформление Issues**	20 Issues с шагами, ожидаемым/фактическим результатом, скриншотами
  
  - **Report.md**	Отчёт о тестировании
  
  - **Summary.md**	Этот документ
  
  ## Не реализовано (и почему)
  
  * **Автоматизация формы «Купить в кредит»**	По требованиям курсового достаточно автоматизировать одну форму. Ручное тестирование второй формы проведено, баги оформлены.
  
  * **API-тесты**	Относится к дополнительным (необязательным) пунктам. Приоритет отдан обязательной части (UI + БД).
  
  * **Параметризация запуска для двух СУБД (MySQL + PostgreSQL)**	Дополнительный пункт. В рамках проекта использована одна СУБД (MySQL).
  
  * **CI (GitHub Actions)**	Требования по подключению CI нет. Дополнительный пункт
  
# 2. Сработавшие риски

   - **Нестабильность симулятора банка**	Запросы иногда обрабатывались с задержкой, из-за чего тесты падали по таймингу.	Увеличена пауза перед проверкой БД до 10 секунд (Selenide.sleep(10000))

   - **Плавающие UI-тесты**	Селекторы кнопок и полей не совпадали с реальным HTML (кнопка «Продолжить» с &nbsp;, поле «Владелец» без placeholder)	Селекторы уточнены через DevTools (XPath по тексту, placeholder, contains(.))

   - **Тайминг записи в БД**	Приложение не успевало сохранить запись до проверки.	Добавлена пауза 10 секунд перед проверкой БД
