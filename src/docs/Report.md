#  1. Краткое описание
   В рамках курсового проекта проведено тестирование веб-сервиса покупки тура aqa-shop, взаимодействующего с СУБД MySQL и симулятором банковских сервисов. Тестирование включало:

*ручное тестирование обеих форм* («Обычная оплата» и «Купить в кредит»);

*автоматизацию UI-тестов для формы «Оплата по карте»* (18 сценариев);

*проверки корректности записи данных в БД после каждого сценария.*

**Окружение:**

ОС: Windows Pro

JDK 11

Gradle 8.14

MySQL 8.0 (Docker)

Selenide 6.19.1, JUnit 5, Allure 2.13.3

Браузер: Chrome

Тестируемый сервис: aqa-shop.jar, порт 8080.
Симулятор банка: 185.154.193.254:9999.

# 4. Общие рекомендации

   *Исправить валидацию полей:*

- месяц 00 должен отклоняться;

- поле «Владелец» должно принимать только латиницу с пробелом (без спецсимволов, без кириллицы, без слитного написания);

- CVC должен принимать только валидное значение.

   *Исправить отображение результата для DECLINED-карты:*

- при статусе DECLINED от банка показывать уведомление «Операция отклонена», а не «Успешно».

- добавить проверку на стороне клиента (frontend), чтобы невалидные данные не отправлялись в банк.
